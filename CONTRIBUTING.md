# Contributing to the Fasting Host guides

Thank you for helping make these guides easier to use.

## Useful contributions

- Correct a broken link or factual error.
- Clarify a confusing instruction.
- Improve a practical checklist.
- Suggest an accessible explanation of a hosting concept.

Open an issue describing the page and proposed correction, or send a pull request with a focused change. Link to the current official service page when changing a price, specification or policy summary.

## Before submitting

1. Read the relevant guide and check for an existing issue.
2. Keep the contribution relevant and easy to review.
3. Verify links and keep Markdown headings and tables readable.
4. Remove all private account, server and payment information.
5. Do not add advertising, unrelated backlinks, fabricated benchmarks or unsupported guarantees.

Service changes, support requests, billing disputes and private security reports belong through [official Fasting Host support](https://fasting.host/contact), not public issues.

This repository contains public documentation, not Fasting Host's production application or infrastructure configuration. Do not upload credentials, customer data or proprietary third-party modules.
