# Getting started with Fasting Host

[Back to README](README.md) · [Support](SUPPORT.md)

## Before ordering

1. Identify the application and its supported OS/runtime.
2. Choose cPanel hosting for a compatible website or a VPS for server-level control.
3. Compare base resources, additions, billing period and recurring total.
4. Check eligible OS choices and service availability.
5. Review payment instructions and the applicable policies.

[Create your account](https://fasting.host/clientarea/register.php) or [sign in](https://fasting.host/clientarea/index.php?rp=/login) using the official website. Use accurate account information and keep your recovery email accessible.

## VPS launch checklist

1. Choose your family, plan, OS and optional additions.
2. Set the root or Administrator access requested for the selected OS. An SSH key is optional.
3. Review and pay the invoice using an available method. Provisioning begins after confirmed payment, subject to availability and the selected configuration.
4. Check the service in your client area and follow its access instructions.
5. Update the guest OS and configure its firewall before exposing applications.
6. Install the application, configure HTTPS where needed and test from an external connection.
7. Set up monitoring and an independent recovery process.

Never put your server password or private key in a public GitHub issue, screenshot or repository.

## cPanel website launch checklist

1. Select a plan with enough storage, databases, mailboxes and domain capacity.
2. Use the cPanel access information supplied for your activated service.
3. Add your domain and configure the required website and email DNS records.
4. Install a compatible application or copy your existing site and database.
5. Select the application-compatible PHP version and review its configuration.
6. Check that AutoSSL completes for the eligible domain after validation succeeds.
7. Test forms, sign-in, mobile pages, email and any store checkout.
8. Keep a separate copy of important website and database data.

## Domain and certificate orders

For a domain, confirm the exact spelling, extension, term, renewal price and registrant details. Follow any legitimate verification or transfer request promptly.

For optional paid SSL, choose the correct coverage, complete issuer validation and follow the installation/reissue instructions. Eligible cPanel hosting already includes free AutoSSL for normal HTTPS.

## Manage your service

Use the [client area](https://fasting.host/clientarea/) for your service, invoices and support. A completed payment, renewal setting or submitted order is not a substitute for checking that the service, domain renewal or certificate issuance actually succeeded.

If something does not work, record the affected page/service, time with timezone, expected result and exact error message. Send those details through [official support](https://fasting.host/contact); redact credentials and payment information.
